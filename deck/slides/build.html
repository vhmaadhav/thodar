Feasibility. Every AI component is an existing, production API from Sarvam AI, the hackathon's technology partner, so the sprint is integration work, not model training. Sarvam Vision (Document AI) digitises paper registers in Tamil and English, about Rs 1 per page; a nurse confirms each row. Sarvam Voice Agents run Saaras v3 speech-to-text, Sarvam-105B and Bulbul v3 text-to-speech for Tamil/English outbound reminder calls over Exotel, writing confirm or reschedule back through tool calls. WhatsApp runs on Meta's Cloud API (utility messages about Rs 0.12–0.15 each); Saaras v3 transcribes voice-note replies (Rs 30 per audio hour). The core is deterministic: versioned schedule rules (ANC, PNC, Universal Immunisation Programme), Splink probabilistic record linking on non-clinical identifiers, FastAPI, PostgreSQL and a Next.js progressive web app. Hosting in AWS Mumbai; Sarvam's models run in India and can be deployed in our own AWS account. Known risks and mitigations: WhatsApp business verification (start week 1, use Meta test number), handwriting OCR errors (nurse confirm screen, Excel import as primary path), no open API for PICME/JANANI/U-WIN (import their exports), families without smartphones (voice path), consent (captured at registration, opt-out on every message).
